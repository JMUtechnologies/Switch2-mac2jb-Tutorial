2. REQUIREMENTS, NETWORK AND DNS

Have the console, installed SmileBASIC edition, compatible Apple Silicon Mac,
mac2jb GUI, USB-C data cable, and Ethernet cables/adapters as needed. A USB
keyboard is useful for manual commands. Keep the USB connection when mac2jb
requests it: Ethernet and USB serve different parts of the workflow.

Connect both devices to the same local network by Ethernet. Avoid guest-network
isolation. In Ready Check, choose the MAC'S ETHERNET IPv4 address, not the
Switch's address, a VPN address, or an inactive Wi-Fi interface. Recheck the
selection after changing adapters or networks.

The linked guide specifies :: in both primary and secondary IPv6 DNS fields
on Switch 2. This may be unsuitable on IPv6-only networks. Save, reconnect,
and verify that the configuration filters Nintendo services on your network.
An ordinary connection test alone does not prove all updates are blocked.

It is not a guarantee against updates; cached addresses, changed endpoints,

3. PREPARE THE MAC AND USB DRIVER

Download mac2jb from its official release page, extract the complete package,
and open the GUI. Follow its bundled driver instructions for that exact version.
https://github.com/cpypwn/mac2jb/releases

The experimental usbgadget.kext needs a compatible Mac and approval/restarts.
For the bundled UNSIGNED driver, current upstream documents SIP changes in
addition to Recovery kernel-extension policy. Reduced Security alone is not
proof that an unsigned driver can load. A working partial/custom SIP setup
should follow upstream's specific guidance rather than be changed blindly.

Apple documents Recovery approval and the security implications here:
https://support.apple.com/guide/security/securely-extending-the-kernel-sec8e454101b/web

Kernel extensions and reduced protections can affect system security/stability.
Review the exact driver source and current instructions before changing policy.
Use the app's Install & load driver action, complete Privacy & Security approval
and required restarts, then refresh its driver status. Do not repeatedly reinstall
just to check status. A successful install/build is not proof of keyboard input.

On Switch 2 set Controllers & Accessories > USB Keyboard to US English.
Confirm the cable supports data and that actual input appears in SmileBASIC.
Mac ports/controller mappings vary; do not copy another model's mapping as fact.

4. TRANSFER THE MATCHING BOOTSTRAP

VERSION NOTE: The upstream release checked for this guide is v0.4.3. Current
mac2jb uses the kurumuz bootstrap with START(PORT,A,B,C,D). Older saved
bootstraps using nine START arguments must be replaced when moving to that
workflow. The contributor's original release was not recorded, so their test
does not establish a test of v0.4.3. Keep bootstrap, host and sender versions
matched. Use the bundled file; do not copy a START command from a screenshot.

Open SmileBASIC > Make a Program with a clean PRG0 editor. Select the app's
bootstrap-typing mode. Set its Demo checkbox to match your edition. Let typing
finish completely, inspect the result, and save using section 5 or 6 below.
Do not interrupt a normal long transfer or start a duplicate over partial code.

5. FULL VERSION: SAVE AND LOAD

With the bootstrap in program slot 0, press X to return to Direct mode. Enter:

SAVE "NS2"

Execute it and confirm the save succeeded. To restore the saved program later,
use this in Direct mode:

LOAD "TXT:NS2"

Accept any loading confirmation and inspect PRG0. Leave the Demo option off
for the full game. The full version does not need the eight-line workaround.

6. DEMO 4.4.6: EIGHT-LINE PRG1 SAVE PROCEDURE

This is the contributor's tested procedure, matching HDR's original gist.
First ensure the COMPLETE bootstrap is already in PRG0. To open the editor,
launch SmileBASIC Demo and enter its Make a Program workspace. With a USB
keyboard, Ctrl+1 selects PRG0 (the transferred bootstrap); Ctrl+2 selects
PRG1 (the helper script). Do not overwrite PRG0 with this helper. Once the
script is entered, press Esc to return to Direct mode (or use the editor's
exit control if Esc behaves differently). Confirm the active program slot
before typing. RUN 1 must be entered in Direct mode, NOT in the editor.

Enter exactly these eight lines in PRG1, without line numbers:

PRGEDIT 0
SRC$=""
FOR I=1 TO PRGSIZE(0)
  L$=PRGGET$()
  SRC$=SRC$+L$
NEXT
SAVEV "TXT:NS2",SRC$
END

Each command occupies its own line. Indent lines 4 and 5 with spaces or Tab.
SRC$="" contains two straight double quotation marks. Include a space after
SAVEV; do not insert spaces inside "TXT:NS2". The optional space after the
comma in HDR's version does not change the command.

Finish editing, return to Direct mode, and enter:

RUN 1

Execute it. RUN 1 belongs in Direct mode, not inside the eight-line program.
Check for errors and confirm NS2 was saved. The helper reads PRG0; an empty
or incomplete PRG0 produces an unusable saved bootstrap even if saving succeeds.

MANUAL DEMO RESTORE / CHECK
Current upstream documents this Direct-mode load command:

PRGEDIT 0:LOADV "TXT:NS2" OUT C$:PRGSET C$

Inspect PRG0 after loading, especially after restarting the console. Compare it
with the matching bundled bootstrap before trusting the saved copy. The current
upstream also documents a shorter two-command save method; this guide retains
the eight-line procedure because that is what the contributor reported testing.
Do not assume the two methods were both tested by this contributor.

Upstream notes that automated demo loading still needs a console test. If GUI
loading fails, check manual restoration and the exact release's instructions.
Do not substitute the full game's LOAD/confirmation sequence without checking
demo behavior. The GUI Demo checkbox selects the edition-specific route.

7. RUN, VERIFY AND FINISH

After saving, restart the console normally, open SmileBASIC and enter Direct
mode. Open mac2jb and select the appropriate run mode. For homebrew, use Held
RPC, which keeps the verified connection open. Here "held" means a live session;
it does not mean a permanent jailbreak.

Select the Mac's Ethernet IPv4 address in Ready Check. Enable the Demo option
only for the demo. Keep both Ethernet connections, the requested USB cable,
and SmileBASIC focus in place. Follow the GUI's prompts for the matching build.

Wait for 4/4 verification AND confirmation that RPC is open before launching
homebrew. Finished typing or a successful USB-send message is not exploit
verification. This guide does not claim all homebrew works on Demo 4.4.6.

Use only the current host session's generated START command. Saving NS2 saves
program text, not live session parameters. Never reuse pairing values from an
old run. Do not send REMOVE twice in the same SmileBASIC process.

When finished, use Finish session and wait for cleanup. Restart the console
before another attempt. If cleanup is uncertain, follow the app's recovery
instructions and restart before retrying. Review logs before sharing them:
they may contain session parameters, machine details or console memory captures.

8. TROUBLESHOOTING

Save failed / NS2 missing
  Check the exact name, straight quotes, PRG0 contents and script syntax. Run
  the helper from PRG1 using RUN 1 in Direct mode. Do not mistake successful
  helper entry for a completed save. Verify a restore after a console restart.

RUN 1 does nothing or gives an error
  Confirm the eight helper lines are in PRG1, not PRG0. Check FOR/NEXT, the
  empty string, dollar signs and PRGSIZE(0). Preserve the bootstrap in PRG0.

USB driver fails / no keyboard input
  Read the exact error and driver logs. Check macOS compatibility, required
  approval/reboot, USB data cable, input focus and controller selection. On
  reported setups USB power direction matters; reconnect if the Mac is charging
  the Switch and enumeration fails. Do not infer a missing driver from every
  helper crash or solve unexplained errors by changing unrelated security settings.

Wrong punctuation or corrupted bootstrap
  Check the Switch USB Keyboard setting is US English. Clear the partial input
  and retransmit after correcting layout. Check both devices before retrying.

Network connection / verification fails
  Reproduce the contributor's Ethernet setup for BOTH devices. Select the Mac's
  active Ethernet IPv4 address. Check same-network reachability, guest isolation,
  host firewall prompts, correct Demo checkbox and matching bootstrap/host build.
  DNS filtering does not replace a reachable local host connection.

Old save stops working after a mac2jb update
  Check the five-argument versus nine-argument bootstrap migration note. Replace
  NS2 using the bootstrap bundled with the version actually running.

Black screen, freeze or failed verification
  Inspect the Mac activity log first. Stop retries; do not immediately repeat
  the exploit in the same console process. If no operation is still running and
  the console is unresponsive, restart it. Keep the exact error for diagnosis.

Download won't open
  Use the official Releases page, extract the complete ZIP and follow that
  release's macOS opening instructions. This repository contains guides only;
  it does not include the mac2jb app or driver.
