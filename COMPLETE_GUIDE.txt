Community guide for Apple Silicon Macs, SmileBASIC full **4.4.9**, and the **Japanese Demo 4.4.6**.

**Updated October 27, 2026** against cpypwn's current README, which documents **v0.5.0**. This is a documentation update, not a new hardware test.

[Complete guide](COMPLETE_GUIDE.txt) · [Official releases](https://github.com/cpypwn/mac2jb/releases) · [Upstream instructions](https://github.com/cpypwn/mac2jb/blob/main/README.md)

## Requirements

- Apple Silicon Mac with macOS 14 or newer.
- Switch 2 firmware **23.0.1**, with SmileBASIC full **4.4.9** or demo **4.4.6**. Upstream says earlier firmware should also work; that is not confirmation of every version.
- SmileBASIC on **internal storage**, with **more than 20 MiB free in its save**.
- USB-C **data cable**, and **both devices connected by Ethernet to the same network**.
- Switch USB Keyboard setting: **US English**.

Before testing, follow the linked [console-update blocking guide](https://consolemods.org/wiki/Switch:Blocking_OFW_Updates#90DNS). DNS filtering can block Nintendo services and cannot guarantee update prevention.

## 1. Prepare the Mac

Download and extract the official release, then open `mac2jb.app`.

The unsigned USB driver requires compatible startup-security and SIP settings. **Keep an existing working partial/custom SIP configuration.** Otherwise follow the Recovery and driver instructions in [the complete guide](COMPLETE_GUIDE.txt) and upstream README. These changes reduce Mac protections.

Use **Install & load driver…**, complete any approval and restart prompts, then refresh driver status. Continue only once the driver is loaded and no driver-install restart is pending. Reinstalling creates another restart requirement.

**USB power direction:** the **Switch supplies power to the Mac**. If the Mac is charging the Switch, disconnect the cable at the Switch, wait about one second, and reconnect it. A loaded driver alone does not prove keyboard input works.

## 2. Choose the matching host and replace the bootstrap

**Demo automation uses BermTheSequel, the default host. Keep that host selected for Demo 4.4.6.**

Developer Options also offers pepsipu and kurumuz. Changing hosts requires typing and saving that host's matching bootstrap. pepsipu does not support held RPC; kurumuz and BermTheSequel do.

**Replace your previous bootstrap, including the one from build 516.** Do not reuse an older NS2 merely because it saved successfully.

1. Open SmileBASIC → **Make a Program**, with an empty **PRG0 / slot 0** editor.
2. Open **First Time Setup** in mac2jb.
3. Tick the demo checkbox for **Demo 4.4.6**; leave it off for the full version.
4. Start typing and let it finish.
5. Press **X** on the Switch controller to return to **Direct mode**.
6. Check that the command prompt is empty, then click **Type Save Command** in mac2jb.
7. Confirm the save on the Switch; overwrite NS2 if prompted.
8. Once saving finishes, confirm saving in mac2jb.

Use Skip only when slot 0 already contains the complete bootstrap matching this build and selected host.

Defaults: **10 ms per key**, **1 second between commands**, and **1 second before load confirmation**. Adjust timing through USB & Timing if needed.

**Editor shortcut:** the original contributor used **Ctrl+1** for the PRG0 editor. The current upstream procedure uses controller **X** to return to Direct mode. Confirm the active slot before typing.

## 3. Manual save/load reference

The GUI can type the save command for you. These are the current upstream manual alternatives; enter them in **Direct mode**.

### Full version

Save:

```basic
SAVE "NS2"
```

Load:

```basic
LOAD "TXT:NS2"
```

Accept the load confirmation.

### Demo 4.4.6

Save the entire bootstrap in slot 0 with this single line:

```basic
PRGEDIT 0:C$="":FOR I=0 TO PRGSIZE(0)-1:C$=C$+PRGGET$() :NEXT:SAVEV "TXT:NS2",C$
```

Load:

```basic
PRGEDIT 0:LOADV "TXT:NS2" OUT C$:PRGSET C$
```

The loop reads every line; a single PRGGET$() call does not save the whole bootstrap. With Demo enabled, mac2jb sends the load command and Enter, waits one second, then sends Enter again to accept OK before RUN.

The older eight-line PRG1 workaround is retained as historical reference in the complete guide; it is no longer the main setup route.

## 4. Run the jailbreak

1. Restart the Switch and open SmileBASIC → **Make a Program → Direct mode**.
2. Connect USB and Ethernet. Select the **Mac's wired IPv4 address** in mac2jb.
3. Check the edition checkbox and matching host. **Demo: BermTheSequel.**
4. Confirm the Switch is ready, then click **Jailbreak**.
5. Keep SmileBASIC focused. Wait for **4/4 verification** and a held connection before launching homebrew.

Typing completion is not exploit verification. A saved NS2 preserves program text, not a live jailbreak or RPC connection.

## 5. Homebrew

Choose **one app per held session**. These are upstream-documented options, not a claim that this guide independently tested each app.

| Option | Use |
| --- | --- |
| GPUBrewLauncher | Hello World, Froggy Road and ftpd-sb; FTP port **5000** |
| HBLauncher v0.2.0 | Original GPU launcher; ftpd-sb uses port **5000** |
| IZLauncher | IZ2S console shell and file exchange through held RPC, including demo through BermTheSequel |
| OunceCake | Exports your own games' unencrypted content; FTP port **2121** |
| Stremio | Requires Stremio on the Mac; leave the manual add-on field empty for account add-ons |

For extra compatible launcher apps, copy the complete app folder into the current session's `vendor/GPUBrewLauncher/apps/` or `vendor/HBLauncher/apps/`, then refresh. New sessions have fresh app libraries; keep originals elsewhere.

Stremio uses a dedicated TCP receiver for larger video/menu frames; audio and session control still use RPC. The Mac must stay connected.

## 6. Finish or retry

Close FTP connections, choose **Finish Session**, and wait for cleanup. **Restart the Switch before another attempt. Never send REMOVE twice in the same SmileBASIC session.**

If typing stops halfway, inspect and clear partial input before retrying. Keep logs for diagnosis, but review them before sharing.

DETAILED MAC RECOVERY AND DRIVER PROCEDURE

Read the current official README before changing startup security:
https://github.com/cpypwn/mac2jb/blob/main/README.md

If the driver already works with a partial/custom SIP setup, retain it.
Otherwise the upstream Recovery route is:
1. Shut down the Mac.
2. Hold power until Loading startup options appears.
3. Choose Options > Continue and authenticate when prompted.
4. Open Utilities > Startup Security Utility.
5. Select the startup disk > Security Policy > Reduced Security.
6. Enable Allow user management of kernel extensions from identified developers.
7. Confirm changes and close Startup Security Utility.
8. Open Utilities > Terminal and enter:
   csrutil disable
9. Follow confirmation/authentication prompts and restart the Mac.
10. In macOS Terminal, check:
    csrutil status
    This route should report System Integrity Protection status: disabled.
    Working partial/custom configurations can report a different status.

Disabling SIP reduces protection. The app does not change it for you.
Fully re-enabling SIP with the unsigned driver has not been verified and
may prevent it working after a kernel-collection rebuild.

Extract the official ZIP and open mac2jb.app. If macOS blocks it, follow
the upstream Privacy & Security > Open Anyway instructions when offered.
Use Install & load driver…, approve the administrator prompt, and allow
the driver in Privacy & Security if requested. Restart when requested.
Reopen mac2jb and refresh driver status. Do not repeatedly reinstall to check.

Apple references:
https://support.apple.com/en-euro/guide/mac-help/mchl768f7291/27/mac/27
https://developer.apple.com/documentation/security/disabling-and-enabling-system-integrity-protection

DEVELOPER OPTIONS AND EXISTING SESSIONS

Host choices:
- BermTheSequel: default; required for the documented demo automation.
- kurumuz: supports held RPC.
- pepsipu: original nine-argument pairing; no held RPC.

Use the bootstrap matching the selected host. Re-type and re-save when
changing hosts. Do not apply the old blanket “all hosts use five arguments”
guidance to pepsipu.

Additional Tools > Run Host Only starts the selected host without typing.
Enable Hold RPC After Success if you want homebrew after verification.
Homebrew launch buttons require 4/4 verification and a held connection.

Additional Tools > RPC Already Held attaches to the original run folder
for a host still running on THIS Mac. The app verifies the live connection.
Disconnecting this attachment leaves the original host running.
Remote hosts and SSH are not supported.

Live Keyboard forwards input while its capture area is focused.
Send Text accepts up to 16 KiB of printable US-keyboard text, tabs and
line breaks. Every line break sends Enter; no extra final Enter is added.
Stop Keyboard cancels the transfer and releases keys.
USB & Timing provides controller selection and adjustable delays.

TROUBLESHOOTING

Driver installed but not loaded:
  Read the exact error. Complete startup-security policy, any approval and
  restart requirements. A successful installation is not proof of USB input.

Power direction wrong:
  The Switch should supply the Mac. Unplug at the Switch, wait about one
  second and reconnect. Confirm direction again.

Corrupt punctuation or incomplete bootstrap:
  Set the Switch USB Keyboard setting to US English. Confirm PRG0 focus.
  Inspect and clear partial input before repeating the transfer.

NS2 missing or incomplete:
  Use Type Save Command with an empty Direct-mode prompt. Confirm saving
  on the Switch and then in mac2jb. For manual demo saving, use the full
  loop above. Inspect PRG0 after restoring it.

Demo fails after an update or host change:
  Select BermTheSequel, tick Demo, and transfer/save its matching current
  bootstrap. Replace old copies, including build 516. Match all components.

Loading hangs:
  Check the edition checkbox. Current demo automation sends Enter, waits
  one second, then sends Enter for OK before RUN. Do not substitute the
  full-version loading sequence blindly. Timing is adjustable.

Network/verification fails:
  Both devices must use Ethernet on the same reachable network per upstream.
  Select the Mac's wired address, not the Switch IP or a VPN interface.
  Check isolation/firewall issues and inspect the host log.
  DNS filtering does not establish local connectivity.

Verification fails or the console freezes:
  Inspect logs and follow cleanup/recovery instructions. Restart the Switch
  before another attempt. Never repeat REMOVE in the same application session.

Homebrew buttons unavailable:
  Wait for 4/4 and a held connection. pepsipu cannot provide held RPC.
  Start a fresh matching session rather than reusing stale pairing values.

Stremio or launcher files disappear:
  Keep the Mac connected during Stremio use. Launcher app libraries are
  recreated for new sessions; retain original compatible app folders elsewhere.

HISTORICAL DEMO SAVE WORKAROUND — OPTIONAL REFERENCE ONLY

The previous guide used HDR's eight-line helper. The current main procedure
is First Time Setup > Type Save Command, or the one-line manual loop above.
This historical procedure is retained for attribution and older reports;
it does not establish a new test of v0.5.0.

In the contributor's earlier keyboard workflow, Ctrl+1 selected PRG0,
Ctrl+2 selected PRG1, and Esc returned to Direct mode. Confirm the slot.
Keep the complete bootstrap in PRG0 and enter the helper only in PRG1.

Enter exactly these eight lines in PRG1, without line numbers:

PRGEDIT 0
SRC$=""
FOR I=1 TO PRGSIZE(0)
  L$=PRGGET$()
  SRC$=SRC$+L$
NEXT
SAVEV "TXT:NS2",SRC$
END

Each command occupies its own line. Indent lines 4 and 5 with spaces or Tab.
SRC$="" contains two straight double quotation marks. Include a space after
SAVEV; do not insert spaces inside "TXT:NS2". The optional space after the
comma in HDR's version does not change the command.

Finish editing, return to Direct mode, and enter:

RUN 1

Execute it. RUN 1 belongs in Direct mode, not inside the eight-line program.
Check for errors and confirm NS2 was saved. The helper reads PRG0; an empty
or incomplete PRG0 produces an unusable saved bootstrap even if saving succeeds.

BUILD FROM SOURCE — OPTIONAL

The upstream README specifies an Apple Silicon Mac, Xcode Command Line
Tools, CMake, and the official Node v24.22.1 macOS arm64 or universal binary.
From the source directory:

bash scripts/check.sh
make gui
build/mac2jb.app/Contents/MacOS/mac2jb --self-test

If needed, set NODE_BINARY to the Node executable's absolute path.
The build prepares pinned homebrew dependencies and produces build/mac2jb.app.
The self-test checks the packaged runtime without sending console commands.
See upstream .github/workflows/build.yml for the full fixture/test list.
